Year 9 · Algebra

Collecting like terms

What you'll learn

  • I can identify the terms, coefficients and constant in an expression.
  • I can tell whether two terms are like terms.
  • I can simplify an expression by collecting like terms, including negative terms.
  • I can collect like terms that contain powers or more than one letter.
  • I can multiply and divide terms, and explain how this is different from adding them.
  • I can write and simplify expressions to solve problems, such as perimeters.

Key words

Variable
A letter that stands for a number that can change, such as \(x\).
Expression
A collection of terms joined by \(+\) and \(-\) signs, such as \(5x - 3y + 7\). It has no equals sign.
Term
One part of an expression, together with the sign in front of it.
Coefficient
The number multiplying a variable. In \(-3y\) the coefficient is \(-3\).
Constant
A term with no variable, just a number, such as \(+7\).
Like terms
Terms with exactly the same letters and powers, such as \(4x^2\) and \(-x^2\).
Simplify
Write an expression in a shorter, neater way without changing its value.

1. Terms, coefficients and constants

An algebraic expression is built from terms. Each term is joined to the next by a \(+\) or \(-\) sign, and the sign belongs to the term that comes after it.

How algebra is written

Instead of…writebecause…
\(3 \times x\) or \(x \times 3\)\(3x\)leave out the \(\times\) sign, number first
\(1x\)\(x\)a coefficient of 1 is not written
\(-1x\)\(-x\)the coefficient is \(-1\), but only the sign is written
\(b \times a\)\(ab\)letters usually go in alphabetical order
\(x \times x\)\(x^2\)a letter times itself is squared
Quick check

For the expression \(4a - b + 9 - 2a^2\):

  1. How many terms are there?
  2. What is the coefficient of \(b\)?
  3. What is the constant?
  4. What is the coefficient of \(a^2\)?
Show answers
  1. 4
  2. \(-1\)
  3. \(9\)
  4. \(-2\)

2. Like terms

Like terms have exactly the same letters raised to exactly the same powers. Only the coefficients can be different.

TermsLike terms?Why
\(3x\) and \(7x\)yesboth are \(x\)
\(3x\) and \(3y\)nodifferent letters
\(2x\) and \(2x^2\)nosame letter, different powers
\(ab\) and \(5ba\)yes\(ba\) is the same as \(ab\)
\(4\) and \(-9\)yesboth are constants
\(x^2y\) and \(xy^2\)no\(x^2y = x \times x \times y\) but \(xy^2 = x \times y \times y\)

Algebra tiles show why unlike terms can't be combined. An \(x^2\) tile, an \(x\) tile and a unit tile are different shapes, so you can count how many of each you have, but you can't turn them into one kind of tile.

Quick check

Which of these are like terms with \(4p\)?

\(7p\)    \(4q\)    \(-p\)    \(p^2\)    \(10pq\)    \(\tfrac{1}{2}p\)

Show answer

\(7p\), \(-p\) and \(\tfrac{1}{2}p\).

3. Collecting like terms

To simplify an expression, add or subtract the coefficients of like terms. The letters stay the same. Think of it as counting: 3 bananas plus 5 bananas is 8 bananas, and \(3x + 5x = 8x\).

Method
  1. Find each group of like terms. It can help to underline each group in a different way.
  2. Add the coefficients in each group. Keep each term's sign with it.
  3. Write the answer with the highest powers first, and the constant last.

One letter

Simplify \(3x + 5x + x\).

Show solution
  1. All three terms are like terms. Remember \(x\) means \(1x\).
  2. \(3 + 5 + 1 = 9\).

\(3x + 5x + x = 9x\)

Two letters

Simplify \(4a + 2b + 3a + 6b\).

Show solution
  1. The \(a\) terms: \(4a + 3a = 7a\).
  2. The \(b\) terms: \(2b + 6b = 8b\).

\(7a + 8b\)

\(7a + 8b\) cannot be simplified further: \(a\) and \(b\) are not like terms.

Quick check
  1. \(2y + 7y\)
  2. \(m + m + m\)
  3. \(5p + 3 + 2p + 4\)
Show answers
  1. \(9y\)
  2. \(3m\)
  3. \(7p + 7\)

4. Collecting negative terms

When some terms are negative, the sign in front of each term travels with it. It helps to rewrite the expression with each group of like terms together before you add.

Subtracting

Simplify (a) \(7y - 2y + 3y\)   (b) \(5x - 8x\).

Show solution
  1. \(7 - 2 + 3 = 8\), so \(7y - 2y + 3y = 8y\).
  2. \(5 - 8 = -3\), so \(5x - 8x = -3x\).

Mixed signs

Simplify \(6a - 3b - 2a + 5b\).

Show solution
  1. Group the like terms, keeping each sign: \(6a - 2a - 3b + 5b\).
  2. \(6a - 2a = 4a\) and \(-3b + 5b = 2b\).

\(4a + 2b\)

Letters and numbers

Simplify \(2p - 5 - 7p + 9\).

Show solution
  1. Group: \(2p - 7p - 5 + 9\).
  2. \(2p - 7p = -5p\) and \(-5 + 9 = 4\).

\(-5p + 4\), which can also be written \(4 - 5p\)

Quick check
  1. \(4k - 9k\)
  2. \(3x - 2y - x + 5y\)
  3. \(8 - 3n - 10 + n\)
Show answers
  1. \(-5k\)
  2. \(2x + 3y\)
  3. \(-2n - 2\)

5. Powers and more than one letter

The same rule applies to terms with powers or several letters: only terms with exactly the same letters and powers can be collected.

Squares

Simplify \(3x^2 + 2x - x^2 + 5x\).

Show solution
  1. The \(x^2\) terms: \(3x^2 - x^2 = 2x^2\).
  2. The \(x\) terms: \(2x + 5x = 7x\).

\(2x^2 + 7x\)

Two letters in a term

Simplify \(4ab + 3ba - ab + 2a\).

Show solution
  1. \(ba\) is the same as \(ab\), so \(4ab\), \(3ba\) and \(-ab\) are like terms: \(4 + 3 - 1 = 6\).
  2. \(2a\) has no partner.

\(6ab + 2a\)

Quick check
  1. \(5y^2 - 2y^2 + y\)
  2. \(7mn - 2nm\)
  3. \(x^2 + 4x - 3x^2 - x\)
Show answers
  1. \(3y^2 + y\)
  2. \(5mn\)
  3. \(-2x^2 + 3x\)

6. Multiplying terms

Any terms can be multiplied together, like or not. Multiply the numbers, then write the letters next to each other.

Multiplying terms

Simplify (a) \(3a \times 4b\)   (b) \(2x \times 5x\)   (c) \(-3m \times 2n\)   (d) \(a \times a \times a\).

Show solution
  1. \(3 \times 4 = 12\) and \(a \times b = ab\): \(12ab\)
  2. \(2 \times 5 = 10\) and \(x \times x = x^2\): \(10x^2\)
  3. \(-3 \times 2 = -6\): \(-6mn\)
  4. \(a^3\)
Adding is not multiplying
AddingMultiplying
\(x + x = 2x\)\(x \times x = x^2\)
\(3x + 2x = 5x\)\(3x \times 2x = 6x^2\)
\(a + b\) can't be simplified\(a \times b = ab\)

  2. \(4p \times 2q\)

7. Dividing terms

Division in algebra is usually written as a fraction. Divide the numbers, then cancel any letters that appear on the top and the bottom.

Dividing terms

Simplify (a) \(12x \div 4\)   (b) \(\dfrac{10ab}{5a}\)   (c) \(\dfrac{6x^2}{3x}\).

Show solution
  1. \(12 \div 4 = 3\): \(3x\)
  2. \(10 \div 5 = 2\); the \(a\) cancels: \(\dfrac{10ab}{5a} = 2b\)
  3. \(6 \div 3 = 2\); \(\dfrac{x^2}{x} = \dfrac{x \times x}{x} = x\): \(2x\)
Quick check
  1. \(20y \div 5\)
  2. \(\dfrac{14pq}{7q}\)
  3. \(\dfrac{9a^2}{3a}\)
Show answers
  1. \(4y\)
  2. \(2p\)
  3. \(3a\)

8. Using simplifying in problems

Perimeter

Find a simplified expression for the perimeter of this rectangle.

Show solution
  1. Add all four sides: \((3x + 2) + (x - 1) + (3x + 2) + (x - 1)\).
  2. \(x\) terms: \(3x + x + 3x + x = 8x\). Constants: \(2 - 1 + 2 - 1 = 2\).

Perimeter \(= 8x + 2\)

An algebra wall

In an algebra wall, each brick is the sum of the two bricks directly below it. Find the expressions in the empty bricks.

Show solution
  1. Middle left: \(2a + (a + 3) = 3a + 3\).
  2. Middle right: \((a + 3) + 5 = a + 8\).
  3. Top: \((3a + 3) + (a + 8) = 4a + 11\).

Middle row \(3a + 3\) and \(a + 8\); top \(4a + 11\)

Simplify first

Find the value of \(4x + 7 - x + 2 - 3x + x\) when \(x = 12\).

Show solution
  1. Simplify first: \(4x - x - 3x + x = x\) and \(7 + 2 = 9\), so the expression is \(x + 9\).
  2. Substitute: \(12 + 9 = 21\).

\(21\)

Simplifying first means one easy substitution instead of four.

Common mistakes

Adding unlike terms

\(5x + 3y\) is not \(8xy\). Different letters cannot be collected. The answer is just \(5x + 3y\).

Forgetting the hidden 1

\(4a - a\) is \(4a - 1a = 3a\), not \(4\). The \(a\) does not disappear.

Mixing up adding and multiplying

\(x + x = 2x\), but \(x \times x = x^2\). And \(2x + 3x^2\) cannot be simplified at all.

Losing the sign

In \(5 - 3x + 2x\), the \(3x\) is negative: \(-3x + 2x = -x\), so the answer is \(5 - x\), not \(5 - 5x\).

Summary

  • A term includes the sign in front of it. The coefficient is the number in front of the letter.
  • Like terms have exactly the same letters and powers.
  • Collect like terms by adding or subtracting their coefficients. The letters do not change.
  • Unlike terms, such as \(x\) and \(x^2\), cannot be collected.
  • To multiply terms, multiply the numbers and write the letters together: \(3x \times 2x = 6x^2\).
  • To divide terms, divide the numbers and cancel letters: \(\dfrac{10ab}{5a} = 2b\).
