Maths

Inline maths goes inside \( … \), for example \(x^2 + 5x + 6 = (x+2)(x+3)\). Money stays plain text: a $45.50 meal is fine.

Display maths goes inside \[ … \]:

\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

Lined-up working uses aligned:

\[ \begin{aligned} 3x + 5 &= 20 \\ 3x &= 15 \\ x &= 5 \end{aligned} \]

Boxes

Key idea

A percentage is a fraction out of 100, so \(35\% = \tfrac{35}{100} = 0.35\).

Rule \[ a^2 + b^2 = c^2 \]
Common mistake

\((x+3)^2\) is not \(x^2 + 9\). Write it as \((x+3)(x+3)\) and expand: \(x^2 + 6x + 9\).

Worked example

Expanding two brackets

Expand and simplify \((x + 4)(x - 2)\).

Show solution
  1. Multiply each term in the first bracket by each term in the second: \(x \cdot x + x \cdot (-2) + 4 \cdot x + 4 \cdot (-2)\)
  2. Simplify each product: \(x^2 - 2x + 4x - 8\)
  3. Collect like terms.

\((x+4)(x-2) = x^2 + 2x - 8\)
