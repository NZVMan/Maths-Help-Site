Year 9 · Algebra

Expanding two brackets

What you'll learn

  • I can explain what expanding means, using the area of a rectangle.
  • I can expand two brackets using the grid method and by multiplying term by term.
  • I can expand brackets that contain negative terms.
  • I can expand a squared bracket such as \((x + 4)^2\) and spot the pattern.
  • I can recognise and use the difference of two squares, \((x + a)(x - a) = x^2 - a^2\).
  • I can expand and simplify longer expressions, and use expanding to solve problems.

Before you start

You will need these skills. Check you can do them before going on. If you get stuck, revisit Expanding single brackets, Collecting like terms or Directed number.

Key words

Expand
Multiply out the brackets so there are no brackets left.
Term
A single part of an expression, separated by \(+\) or \(-\) signs. \(x^2 + 5x - 3\) has three terms.
Like terms
Terms with exactly the same letters and powers, such as \(5x\) and \(-2x\). They can be added together.
Coefficient
The number in front of a letter. In \(7x\) the coefficient is \(7\).
Constant
A term that is just a number, such as \(+15\).
Binomial
An expression with two terms, such as \(x + 3\).
Quadratic expression
An expression where the highest power of \(x\) is \(x^2\), such as \(x^2 + 8x + 15\).

1. Multiplying two brackets

You already know how to expand one bracket: \(3(a + 2) = 3a + 6\). The number outside multiplies each term inside.

Two brackets work the same way, but now there are two terms on the outside as well. A good way to see what happens is to think about the area of a rectangle.

Suppose a rectangle is \(a + 2\) tall and \(b + 3\) wide. Its area is \((a + 2)(b + 3)\). Split it into four smaller rectangles:

Adding the four areas gives

\[ (a + 2)(b + 3) = ab + 3a + 2b + 6 \]

Here there are no like terms, so the answer has four terms.

Key idea

Every term in the first bracket multiplies every term in the second bracket. Two terms times two terms gives four products.

Different letters

Expand \((p + 5)(q + 1)\).

Show solution
  1. \(p \times q = pq\)
  2. \(p \times 1 = p\)
  3. \(5 \times q = 5q\)
  4. \(5 \times 1 = 5\)

\((p + 5)(q + 1) = pq + p + 5q + 5\)

Quick check
  1. Expand \((m + 4)(n + 2)\)
  2. Expand \((a + 1)(b + 7)\)
Show answers
  1. \(mn + 2m + 4n + 8\)
  2. \(ab + 7a + b + 7\)

2. The grid method

When both brackets contain the same letter, two of the four products are like terms, and you can collect them.

Think of \((x + 3)(x + 5)\) as the area of a rectangle that is \(x + 3\) tall and \(x + 5\) wide.

The grid method is the same idea without drawing the rectangle to scale. Put one bracket across the top and the other down the side, then multiply to fill each box.

\((x + 3)(x + 5)\)
\(\times\)\(x\)\(+5\)
\(x\)\(x^2\)\(+5x\)
\(+3\)\(+3x\)\(+15\)

Add the four boxes, then collect the like terms \(5x\) and \(3x\):

\[ (x + 3)(x + 5) = x^2 + 5x + 3x + 15 = x^2 + 8x + 15 \]

Notice that the like terms always sit on the diagonal of the grid.

Rule \[ (a + b)(c + d) = ac + ad + bc + bd \]

Using a grid

Expand and simplify \((x + 2)(x + 6)\).

Show solution
\(\times\)\(x\)\(+6\)
\(x\)\(x^2\)\(+6x\)
\(+2\)\(+2x\)\(+12\)
  1. Write out the four boxes: \(x^2 + 6x + 2x + 12\).
  2. Collect like terms: \(6x + 2x = 8x\).

\((x + 2)(x + 6) = x^2 + 8x + 12\)

A larger number

Expand and simplify \((x + 10)(x + 4)\).

Show solution
  1. The four products are \(x^2\), \(+4x\), \(+10x\) and \(+40\).
  2. Collect like terms: \(4x + 10x = 14x\).

\((x + 10)(x + 4) = x^2 + 14x + 40\)

Quick check
  1. \((x + 3)(x + 4)\)
  2. \((x + 2)(x + 10)\)
  3. \((x + 5)(x + 1)\)
Show answers
  1. \(x^2 + 7x + 12\)
  2. \(x^2 + 12x + 20\)
  3. \(x^2 + 6x + 5\)

3. Multiplying term by term

Once you are confident with the grid, you can multiply without drawing it. Work through the four products in a fixed order so you never miss one. Many people remember the order with the word FOIL:

The Outer and Inner products are the like terms in the middle. FOIL only works for two brackets with two terms each. The grid method works for any brackets, so it is worth keeping for harder questions.

Term by term

Expand and simplify \((x + 7)(x + 2)\).

Show solution
  1. First: \(x \times x = x^2\)
  2. Outer: \(x \times 2 = 2x\)
  3. Inner: \(7 \times x = 7x\)
  4. Last: \(7 \times 2 = 14\)
  5. Collect like terms: \(x^2 + 2x + 7x + 14 = x^2 + 9x + 14\)

\((x + 7)(x + 2) = x^2 + 9x + 14\)

4. Brackets with negative terms

A bracket such as \((x - 3)\) has the terms \(x\) and \(-3\). The minus sign belongs to the \(3\). Keep it with the number when you multiply, and use the rules for multiplying directed numbers.

Sign rules for multiplying
\(\times\)positivenegative
positivepositivenegative
negativenegativepositive

One negative term

Expand and simplify \((x + 5)(x - 3)\).

Show solution
\(\times\)\(x\)\(-3\)
\(x\)\(x^2\)\(-3x\)
\(+5\)\(+5x\)\(-15\)
  1. Write out the boxes: \(x^2 - 3x + 5x - 15\).
  2. Collect like terms: \(-3x + 5x = 2x\).

\((x + 5)(x - 3) = x^2 + 2x - 15\)

Negative first

Expand and simplify \((x - 6)(x + 2)\).

Show solution
  1. First: \(x \times x = x^2\). Outer: \(x \times 2 = 2x\). Inner: \((-6) \times x = -6x\). Last: \((-6) \times 2 = -12\).
  2. Collect like terms: \(2x - 6x = -4x\).

\((x - 6)(x + 2) = x^2 - 4x - 12\)

Two negative terms

Expand and simplify \((x - 4)(x - 7)\).

Show solution
  1. First: \(x^2\). Outer: \(x \times (-7) = -7x\). Inner: \((-4) \times x = -4x\). Last: \((-4) \times (-7) = +28\).
  2. Collect like terms: \(-7x - 4x = -11x\).

\((x - 4)(x - 7) = x^2 - 11x + 28\)

A negative times a negative is positive, so the constant at the end is \(+28\).

Quick check
  1. \((x + 3)(x - 5)\)
  2. \((x - 2)(x - 9)\)
  3. \((x - 8)(x + 1)\)
Show answers
  1. \(x^2 - 2x - 15\)
  2. \(x^2 - 11x + 18\)
  3. \(x^2 - 7x - 8\)

5. Squaring a bracket

A squared bracket means the bracket multiplied by itself: \((x + 3)^2 = (x + 3)(x + 3)\). As an area, it is a square with side \(x + 3\).

There are two rectangles of area \(3x\), so the middle term is \(6x\). This always happens when you square a bracket: the middle term is double the number times \(x\), and the last term is the number squared.

Perfect squares \[ (x + a)^2 = x^2 + 2ax + a^2 \qquad (x - a)^2 = x^2 - 2ax + a^2 \]

Squaring with a plus

Expand and simplify \((x + 4)^2\).

Show solution
  1. Write it as two brackets: \((x + 4)(x + 4)\).
  2. Multiply every term by every term: \(x^2 + 4x + 4x + 16\).
  3. Collect like terms: \(4x + 4x = 8x\).

\((x + 4)^2 = x^2 + 8x + 16\)

Check with the pattern: double \(4\) is \(8\), and \(4^2 = 16\).

Squaring with a minus

Expand and simplify \((x - 5)^2\).

Show solution
  1. Write it as two brackets: \((x - 5)(x - 5)\).
  2. Multiply: \(x^2 - 5x - 5x + 25\). The last term is \((-5) \times (-5) = +25\).
  3. Collect like terms: \(-5x - 5x = -10x\).

\((x - 5)^2 = x^2 - 10x + 25\)

Quick check
  1. \((x + 6)^2\)
  2. \((x - 1)^2\)
  3. \((x + 10)^2\)
Show answers
  1. \(x^2 + 12x + 36\)
  2. \(x^2 - 2x + 1\)
  3. \(x^2 + 20x + 100\)

6. The difference of two squares

Something surprising happens when the two brackets have the same numbers but opposite signs.

The middle terms cancel

Expand and simplify \((x + 5)(x - 5)\).

Show solution
  1. First: \(x^2\). Outer: \(-5x\). Inner: \(+5x\). Last: \(-25\).
  2. Collect like terms: \(-5x + 5x = 0\), so there is no \(x\) term.

\((x + 5)(x - 5) = x^2 - 25\)

The answer is one square (\(x^2\)) take away another square (\(25 = 5^2\)), which is why it is called the difference of two squares.

Difference of two squares \[ (x + a)(x - a) = x^2 - a^2 \]
Investigate

Work out \(21 \times 19\) without a calculator by writing it as \((20 + 1)(20 - 1)\). Then try \(32 \times 28\) and \(105 \times 95\). Why does this trick work?

Show answers

\(21 \times 19 = 20^2 - 1^2 = 399\). \(32 \times 28 = 30^2 - 2^2 = 896\). \(105 \times 95 = 100^2 - 5^2 = 9975\). It works because \((a + b)(a - b) = a^2 - b^2\) for any numbers.

Quick check
  1. \((x + 2)(x - 2)\)
  2. \((x - 7)(x + 7)\)
  3. \((y + 10)(y - 10)\)
Show answers
  1. \(x^2 - 4\)
  2. \(x^2 - 49\)
  3. \(y^2 - 100\)

7. A shortcut: add and multiply

Look back at the answers so far. In every case where both brackets start with \(x\):

  • the number in front of \(x\) is the two numbers added, and
  • the constant at the end is the two numbers multiplied.
Rule \[ (x + a)(x + b) = x^2 + (a + b)x + ab \]
BracketsAddMultiplyExpanded
\((x + 2)(x + 5)\)\(2 + 5 = 7\)\(2 \times 5 = 10\)\(x^2 + 7x + 10\)
\((x + 6)(x - 4)\)\(6 + (-4) = 2\)\(6 \times (-4) = -24\)\(x^2 + 2x - 24\)
\((x - 3)(x - 5)\)\(-3 + (-5) = -8\)\((-3) \times (-5) = 15\)\(x^2 - 8x + 15\)
Why this matters

Factorising is expanding in reverse. To factorise \(x^2 + 7x + 10\), you look for two numbers that add to \(7\) and multiply to \(10\). See Factorising.

Quick check

Use the shortcut.

  1. \((x + 7)(x + 3)\)
  2. \((x - 9)(x + 2)\)
  3. \((x - 6)(x - 6)\)
Show answers
  1. \(x^2 + 10x + 21\)
  2. \(x^2 - 7x - 18\)
  3. \(x^2 - 12x + 36\)

8. Expanding and simplifying longer expressions

Some questions have more than one pair of brackets, or a number in front. Expand each part first, then collect like terms.

Adding two expansions

Expand and simplify \((x + 1)(x + 4) + (x + 2)(x + 3)\).

Show solution
  1. Expand the first pair: \((x + 1)(x + 4) = x^2 + 5x + 4\).
  2. Expand the second pair: \((x + 2)(x + 3) = x^2 + 5x + 6\).
  3. Add: \(x^2 + 5x + 4 + x^2 + 5x + 6\).
  4. Collect like terms.

\(2x^2 + 10x + 10\)

Subtracting an expansion

Expand and simplify \((x + 5)(x + 2) - (x + 1)(x + 3)\).

Show solution
  1. Expand each pair, keeping the second answer in brackets: \((x^2 + 7x + 10) - (x^2 + 4x + 3)\).
  2. The minus sign changes the sign of every term in the second bracket: \(x^2 + 7x + 10 - x^2 - 4x - 3\).
  3. Collect like terms: \(x^2 - x^2 = 0\), \(7x - 4x = 3x\), \(10 - 3 = 7\).

\(3x + 7\)

A number in front

Expand and simplify \(3(x + 2)(x - 1)\).

Show solution
  1. Expand the two brackets first: \((x + 2)(x - 1) = x^2 - x + 2x - 2 = x^2 + x - 2\).
  2. Multiply every term by \(3\): \(3(x^2 + x - 2)\).

\(3x^2 + 3x - 6\)

Expanding in a problem

A square garden has sides of \(x\) metres. A path 2 m wide is built all the way around it. Find an expression for the area of the path.

Show solution
  1. Area of the outer square: \((x + 4)^2 = x^2 + 8x + 16\).
  2. Area of the garden: \(x^2\).
  3. Path = outer square − garden: \(x^2 + 8x + 16 - x^2\).

Area of path \(= 8x + 16\) m²

Check with \(x = 6\): outer square \(10^2 = 100\), garden \(36\), path \(64\). Formula: \(8 \times 6 + 16 = 64\). ✓

Common mistakes

Squaring each term

\((x + 3)^2\) is not \(x^2 + 9\). Write it as \((x + 3)(x + 3)\) and you will see the middle terms: \(x^2 + 6x + 9\).

Only multiplying firsts and lasts

\((x + 2)(x + 5)\) is not \(x^2 + 10\). There must be four products before you simplify.

Losing a negative

In \((x - 4)(x - 7)\) the last product is \((-4) \times (-7) = +28\), not \(-28\). Write each sign in the grid before you multiply.

Subtracting a bracket

\(-(x^2 + 4x + 3)\) is \(-x^2 - 4x - 3\). The minus changes the sign of every term, not just the first one.

Summary

  • Every term in the first bracket multiplies every term in the second: four products, then collect like terms.
  • The grid method and FOIL are two ways of making sure you get all four products.
  • Keep each sign with its number: \((x - 3)\) means \(x\) and \(-3\).
  • \((x + a)(x + b) = x^2 + (a + b)x + ab\): add for the middle, multiply for the end.
  • \((x + a)^2 = x^2 + 2ax + a^2\) and \((x - a)^2 = x^2 - 2ax + a^2\).
  • \((x + a)(x - a) = x^2 - a^2\): the difference of two squares.
