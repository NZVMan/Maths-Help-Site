Year 10 · Algebra

Quadratic graphs

What you'll learn

  • I can name the key features of a parabola: turning point, axis of symmetry, \(x\)-intercepts and \(y\)-intercept.
  • I can sketch a parabola from factorised form, \(y = (x - p)(x - q)\).
  • I can sketch a parabola from turning-point form, \(y = a(x - h)^2 + k\).
  • I can write the equation of a parabola from its graph.

Key ideas

Key idea

The graph of a quadratic, such as \(y = x^2 - 2x - 3\), is a symmetrical U-shaped curve called a parabola.

Features of a parabola

This is the graph of \(y = x^2 - 2x - 3\).

FeatureWhat it isOn this graph
\(x\)-intercepts (roots)where the curve crosses the \(x\)-axis (\(y = 0\))\(x = -1\) and \(x = 3\)
\(y\)-interceptwhere the curve crosses the \(y\)-axis (\(x = 0\))\(y = -3\)
Turning point (vertex)the lowest (or highest) point\((1, -4)\)
Axis of symmetrythe vertical mirror line through the turning point\(x = 1\)

The axis of symmetry is always exactly halfway between the two \(x\)-intercepts: \(\dfrac{-1 + 3}{2} = 1\).

Three ways to write the same quadratic

Each form shows you a different feature straight away. All three of these describe the graph above.

FormExampleRead off
Expanded\(y = x^2 - 2x - 3\)\(y\)-intercept: the number on the end, \(-3\)
Factorised\(y = (x + 1)(x - 3)\)\(x\)-intercepts: \(x = -1\) and \(x = 3\)
Turning point\(y = (x - 1)^2 - 4\)turning point: \((1, -4)\)
Turning-point form \[ y = a(x - h)^2 + k \quad\text{has its turning point at } (h, k) \]

If \(a\) is positive the parabola opens upwards (∪). If \(a\) is negative it opens downwards (∩).

Worked examples

Sketching from factorised form

Sketch \(y = (x - 2)(x + 4)\). Label the intercepts and the turning point.

Show solution
  1. \(x\)-intercepts: set each bracket to zero. \(x - 2 = 0\) gives \(x = 2\); \(x + 4 = 0\) gives \(x = -4\).
  2. \(y\)-intercept: put \(x = 0\). \(y = (0 - 2)(0 + 4) = -8\).
  3. Axis of symmetry: halfway between the roots. \(x = \dfrac{2 + (-4)}{2} = -1\).
  4. Turning point: put \(x = -1\). \(y = (-1 - 2)(-1 + 4) = (-3)(3) = -9\), so \((-1, -9)\).
  5. The \(x^2\) term is positive, so it opens upwards.

Sketching from turning-point form

Sketch \(y = -(x - 3)^2 + 4\). Label the intercepts and the turning point.

Show solution
  1. Turning point: compare with \(y = a(x - h)^2 + k\). Here \(h = 3\) and \(k = 4\), so \((3, 4)\).
  2. \(a = -1\) is negative, so it opens downwards and \((3, 4)\) is a maximum.
  3. \(y\)-intercept: \(y = -(0 - 3)^2 + 4 = -9 + 4 = -5\).
  4. \(x\)-intercepts: set \(y = 0\). \((x - 3)^2 = 4\), so \(x - 3 = \pm 2\), giving \(x = 1\) and \(x = 5\).

Finding the equation from a graph

Find the equation of this parabola.

Show solution
  1. The \(x\)-intercepts are \(-2\) and \(4\), so the brackets are \((x + 2)\) and \((x - 4)\): \(y = a(x + 2)(x - 4)\).
  2. Use the \(y\)-intercept to find \(a\). At \(x = 0\): \(-8 = a(2)(-4) = -8a\), so \(a = 1\).

\(y = (x + 2)(x - 4)\), or expanded, \(y = x^2 - 2x - 8\)

Common mistakes

Common mistake

Getting the sign wrong. \(y = (x + 4)(x - 1)\) crosses the \(x\)-axis at \(x = -4\) and \(x = 1\): the signs swap. In the same way, \(y = (x - 3)^2 + 2\) has its turning point at \((3, 2)\), not \((-3, 2)\).

Common mistake

Forgetting to check \(a\). A negative number in front of the \(x^2\) (or the bracket) flips the parabola upside down.

Try these

For questions 1–5, find the \(x\)-intercepts (if any), the \(y\)-intercept and the turning point, then sketch the graph.

  1. \(y = (x - 1)(x - 5)\)
  2. \(y = (x + 3)(x - 1)\)
  3. \(y = x^2 - 4\)
  4. \(y = (x - 2)^2 + 1\)
  5. \(y = -(x + 1)^2 + 9\)
  6. A parabola crosses the \(x\)-axis at \(0\) and \(6\), and has its turning point at \((3, -9)\). Find its equation.
Show answers
  1. \(x\)-intercepts \(1\) and \(5\); \(y\)-intercept \(5\); turning point \((3, -4)\).
  2. \(x\)-intercepts \(-3\) and \(1\); \(y\)-intercept \(-3\); turning point \((-1, -4)\).
  3. \(x\)-intercepts \(-2\) and \(2\); \(y\)-intercept \(-4\); turning point \((0, -4)\).
  4. No \(x\)-intercepts (the lowest point is above the \(x\)-axis); \(y\)-intercept \(5\); turning point \((2, 1)\).
  5. Opens downwards. \(x\)-intercepts \(-4\) and \(2\); \(y\)-intercept \(8\); turning point \((-1, 9)\).
  6. \(y = a\,x(x - 6)\). At \(x = 3\): \(-9 = a(3)(-3) = -9a\), so \(a = 1\) and \(y = x(x - 6) = x^2 - 6x\).
