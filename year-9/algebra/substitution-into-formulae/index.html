Substitution into formulae

What you'll learn

  • I can explain what substitution means and spot the hidden multiplication signs in algebra.
  • I can substitute numbers into an expression and use the order of operations.
  • I can substitute negative numbers, using brackets.
  • I can substitute into expressions with powers and square roots, such as \(3x^2\) and \(\sqrt{a^2 + b^2}\).
  • I can use everyday formulae and give answers with the right units.
  • I can find an unknown that is not the subject of a formula.

Key words

Variable
A letter that stands for a number that can change, such as \(x\) or \(t\).
Expression
A collection of terms with no equals sign, such as \(3a + 5\).
Formula
A rule, written with letters, that links two or more quantities, such as \(A = lw\). The plural is formulae.
Subject
The letter on its own on one side of a formula. In \(A = lw\), the subject is \(A\).
Substitute
Replace each letter with a number.
Evaluate
Work out the value of an expression.
Order of operations
The order calculations are done in: brackets, exponents (powers and roots), division and multiplication, then addition and subtraction. Often remembered as BEDMAS.

1. What substitution means

In algebra a letter stands for a number. When you know the number, you can substitute it: take out the letter and put the number in its place. Then you can evaluate the expression, which means work out its value.

Algebra hides some multiplication signs. Before you substitute, put them back in. The table shows what each expression means and its value when \(a = 4\) and \(b = 3\).

Written asMeansWhen \(a = 4\), \(b = 3\)
\(3a\)\(3 \times a\)\(3 \times 4 = 12\)
\(ab\)\(a \times b\)\(4 \times 3 = 12\)
\(2ab\)\(2 \times a \times b\)\(2 \times 4 \times 3 = 24\)
\(a^2\)\(a \times a\)\(4 \times 4 = 16\)
\(\dfrac{a}{2}\)\(a \div 2\)\(4 \div 2 = 2\)
\(2(a + b)\)\(2 \times (a + b)\)\(2 \times 7 = 14\)
Key idea

When \(a = 4\), \(3a\) means \(3 \times 4 = 12\). It is not 34. Write the \(\times\) sign in before you substitute.

2. Using the order of operations

Once the numbers are in, the calculation follows the usual order of operations. Substituting doesn't change the order.

Order of operations (BEDMAS)
  1. Brackets first.
  2. Exponents: powers and roots.
  3. Division and Multiplication, working from left to right.
  4. Addition and Subtraction, working from left to right.

A fraction line acts like brackets: work out the whole top and the whole bottom first, then divide.

Brackets make a difference

Find the value of each expression when \(a = 4\), \(b = 5\) and \(c = 2\).

(a) \(a + bc\)   (b) \((a + b)c\)   (c) \(\dfrac{a + b + 3}{c}\)   (d) \(ab - 2c\)

Show solution
  1. Multiply first: \(4 + 5 \times 2 = 4 + 10 = 14\)
  2. Bracket first: \((4 + 5) \times 2 = 9 \times 2 = 18\)
  3. Work out the top first: \(\dfrac{4 + 5 + 3}{2} = \dfrac{12}{2} = 6\)
  4. \(4 \times 5 - 2 \times 2 = 20 - 4 = 16\)

The mean

The mean of three numbers \(a\), \(b\) and \(c\) is \(\dfrac{a + b + c}{3}\). Find the mean of 7, 12 and 14.

Show solution
  1. Substitute: \(\dfrac{7 + 12 + 14}{3}\).
  2. The fraction line acts like brackets, so add first: \(\dfrac{33}{3}\).

Mean \(= 11\)

On a calculator, type (7 + 12 + 14) ÷ 3. Without the brackets the calculator works out \(7 + 12 + \frac{14}{3} \approx 23.7\), which is wrong.

3. Substituting negative numbers

When you substitute a negative number, put it in brackets. The brackets keep the negative sign with its number, so you don't mix it up with a subtraction sign. Then use the rules for directed number.

\[ x = -3: \quad 2x + 10 = 2 \times (-3) + 10 = -6 + 10 = 4 \]
RuleExample
Subtracting a negative is the same as adding\(5 - (-2) = 5 + 2 = 7\)
Positive \(\times\) negative is negative\(4 \times (-2) = -8\)
Negative \(\times\) negative is positive\((-4) \times (-3) = 12\)

4. Powers and square roots

A power only applies to the thing directly underneath it. In \(3x^2\), only the \(x\) is squared, so \(3x^2 = 3 \times x^2\). To square the whole of \(3x\), it needs brackets: \((3x)^2 = 3x \times 3x = 9x^2\).

The table shows the difference when \(x = 4\) and when \(x = -3\). Put a negative number in brackets before you square it: \((-3)^2 = (-3) \times (-3) = 9\).

ExpressionMeans\(x = 4\)\(x = -3\)
\(x^2\)\(x \times x\)\(16\)\(9\)
\(3x^2\)\(3 \times x \times x\)\(48\)\(27\)
\((3x)^2\)\(3x \times 3x\)\(144\)\(81\)
\(-x^2\)\(-(x \times x)\)\(-16\)\(-9\)
\(x^3\)\(x \times x \times x\)\(64\)\(-27\)
Calculator tip

To square \(-3\), type (−3)² with the brackets. Without them, most calculators work out \(-(3^2) = -9\).

Powers

Find the value of each expression when \(x = 5\).

(a) \(x^2 + 2\)   (b) \(2x^2\)   (c) \((2x)^2\)   (d) \(x^3 - x\)

Show solution
  1. \(5^2 + 2 = 25 + 2 = 27\)
  2. Square first, then multiply: \(2 \times 5^2 = 2 \times 25 = 50\)
  3. Bracket first: \((2 \times 5)^2 = 10^2 = 100\)
  4. \(5^3 - 5 = 125 - 5 = 120\)

Powers of a negative number

Find the value of each expression when \(x = -2\).

(a) \(x^2\)   (b) \(5x^2\)   (c) \(x^3\)   (d) \(10 - x^2\)

Show solution
  1. \((-2)^2 = (-2) \times (-2) = 4\)
  2. \(5 \times (-2)^2 = 5 \times 4 = 20\)
  3. \((-2)^3 = (-2) \times (-2) \times (-2) = -8\)
  4. \(10 - (-2)^2 = 10 - 4 = 6\)

A square root sign acts like a bracket too: work out everything underneath it first, then take the root.

A square root

In a right-angled triangle, the longest side is \(c = \sqrt{a^2 + b^2}\), where \(a\) and \(b\) are the two shorter sides. Find \(c\) when \(a = 8\) cm and \(b = 15\) cm.

Show solution
  1. Substitute: \(c = \sqrt{8^2 + 15^2}\).
  2. Work out underneath the root first: \(c = \sqrt{64 + 225} = \sqrt{289}\).

\(c = 17\) cm

This is Pythagoras' theorem.

Investigate

The expression \(n^2 - n + 41\) was studied by the mathematician Leonhard Euler in 1772.

  • Substitute \(n = 1, 2, 3, 4, 5\) and \(6\). Is each answer a prime number?
  • Do you think the answer is always prime? Try a few larger values of \(n\).
  • Now try \(n = 41\). What do you notice?
Show answer

The values are 41, 43, 47, 53, 61 and 71, which are all prime. In fact every value from \(n = 1\) to \(n = 40\) is prime. But when \(n = 41\), \(41^2 - 41 + 41 = 41^2 = 1681\), which is \(41 \times 41\) and not prime. Trying lots of examples can suggest a pattern, but it doesn't prove the pattern always holds.

5. Using formulae

A formula is a rule that links quantities. Most formulae have a subject: the letter on its own on the left. To use a formula, substitute the values you know on the right, then work out the subject.

FormulaSubjectWhat the letters stand for
\(P = 2l + 2w\)\(P\)perimeter of a rectangle with length \(l\) and width \(w\)
\(A = \tfrac{1}{2}bh\)\(A\)area of a triangle with base \(b\) and height \(h\)
\(s = \dfrac{d}{t}\)\(s\)average speed for distance \(d\) travelled in time \(t\)
\(F = 1.8C + 32\)\(F\)temperature in °F for a temperature of \(C\) °C
Units

An answer to a real-life formula needs units: cm, m², $, km/h and so on. Check that the values you substitute are in matching units first. For example, don't mix metres and centimetres.

A taxi fare

A taxi company works out its fares with the formula \(C = 3.50 + 2.80k\), where \(C\) is the cost in dollars and \(k\) is the distance in kilometres.

(a) Find the cost of a 12 km trip.   (b) Complete a table of values for trips of 0, 5, 10, 15 and 20 km.

Show solution
  1. \(C = 3.50 + 2.80 \times 12 = 3.50 + 33.60 = 37.10\). The fare is $37.10.
  2. Substitute each distance in turn:
    \(k\) (km)05101520

Celsius to Fahrenheit

The USA measures temperature in degrees Fahrenheit (°F). The formula \(F = 1.8C + 32\) changes a Celsius temperature \(C\) into Fahrenheit. Change (a) 25 °C   (b) −10 °C into Fahrenheit.

Show solution
  1. \(F = 1.8 \times 25 + 32 = 45 + 32 = 77\). So 25 °C is 77 °F.
  2. \(F = 1.8 \times (-10) + 32 = -18 + 32 = 14\). So −10 °C is 14 °F.
Explore

  • Water freezes at 0 °C and boils at 100 °C. What are these in Fahrenheit?
  • Normal body temperature is about 37 °C. Is that hotter or colder than 100 °F?
  • Find the one temperature that is the same number in both scales.
Show answers

0 °C is 32 °F, and 100 °C is 212 °F. Body temperature is \(1.8 \times 37 + 32 = 98.6\) °F, so it is a little colder than 100 °F. At \(C = -40\), \(F = 1.8 \times (-40) + 32 = -72 + 32 = -40\), so −40 °C is the same as −40 °F.

Area of a trapezium

The area of a trapezium is \(A = \tfrac{1}{2}(a + b)h\), where \(a\) and \(b\) are the parallel sides and \(h\) is the height. A garden bed is a trapezium with parallel sides 7 m and 11 m, 4 m apart. Find its area.

Show solution
  1. Substitute \(a = 7\), \(b = 11\) and \(h = 4\): \(A = \tfrac{1}{2} \times (7 + 11) \times 4\).
  2. Bracket first: \(A = \tfrac{1}{2} \times 18 \times 4 = 9 \times 4\).

\(A = 36\) m²

6. Finding a value that isn't the subject

Sometimes you know the subject and need one of the other letters. Substitute every value you know. This leaves an equation with one unknown, which you can solve with inverse operations. See Linear equations for more on solving.

A missing width

A rectangle has perimeter 30 cm and length 9 cm. Use \(P = 2l + 2w\) to find its width.

Show solution
  1. Substitute \(P = 30\) and \(l = 9\): \(30 = 2 \times 9 + 2w\), so \(30 = 18 + 2w\).
  2. Subtract 18 from both sides: \(12 = 2w\).
  3. Divide both sides by 2: \(w = 6\).

The width is 6 cm.

Check: \(2 \times 9 + 2 \times 6 = 18 + 12 = 30\). ✓

A missing acceleration

The formula \(v = u + at\) gives the speed \(v\) of a car that starts at speed \(u\) and speeds up by \(a\) metres per second every second for \(t\) seconds. Find \(a\) when \(v = 25\), \(u = 5\) and \(t = 4\).

Show solution
  1. Substitute: \(25 = 5 + a \times 4\), so \(25 = 5 + 4a\).
  2. Subtract 5 from both sides: \(20 = 4a\).
  3. Divide both sides by 4: \(a = 5\).

\(a = 5\) m/s per second

Quick check
  1. \(A = lw\). Find \(w\) when \(A = 48\) and \(l = 8\).
  2. \(F = 1.8C + 32\). Find \(C\) when \(F = 50\).
  3. \(C = 3.50 + 2.80k\). Find \(k\) when \(C = 31.50\).
Show answers
  1. \(48 = 8w\), so \(w = 6\)
  2. \(50 = 1.8C + 32\), so \(18 = 1.8C\) and \(C = 10\)
  3. \(31.50 = 3.50 + 2.80k\), so \(28 = 2.8k\) and \(k = 10\)

Common mistakes

Forgetting the hidden ×

When \(a = 4\), \(3a = 3 \times 4 = 12\), not 34. And \(ab\) means \(a \times b\).

No brackets round a negative

When \(x = -3\), \(x^2 = (-3)^2 = 9\), not \(-9\). Always put a negative number in brackets when you substitute it.

Squaring too much

When \(x = 4\), \(3x^2 = 3 \times 16 = 48\). Only the \(x\) is squared. \((3x)^2 = 12^2 = 144\) is a different expression.

Ignoring the fraction line

\(\dfrac{a + b}{2}\) means add first, then divide. On a calculator, type the brackets yourself: (a + b) ÷ 2.

Summary

  • To substitute, replace each letter with its number, then evaluate.
  • Put back the hidden multiplication signs: \(3a = 3 \times a\) and \(ab = a \times b\).
  • Follow the order of operations (BEDMAS). A fraction line and a square root sign act like brackets.
  • Put negative numbers in brackets: \((-3)^2 = 9\).
  • In \(3x^2\) only the \(x\) is squared. \((3x)^2\) squares everything in the bracket.
  • A formula links quantities. Substitute the values you know, then give the answer with units.
  • To find a letter that isn't the subject, substitute, then solve the equation that's left.
